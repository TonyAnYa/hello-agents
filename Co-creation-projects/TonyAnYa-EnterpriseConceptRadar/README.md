# EnterpriseConceptRadar

EnterpriseConceptRadar 使用 DeepSeek 大模型和 SerpAPI 搜索真实能源政策，发现新词、新概念和制度安排，分析其对广东电网的影响，并生成本地 Markdown/JSON 智能简报。

## 客户只需要运行一个安装文件

发行压缩包不包含任何人的 API Key。

macOS：

```bash
./setup_macos.command
```

Windows：

```bat
setup_windows.cmd
```

安装脚本自动完成：

```text
安装程序
→ 填写并核对自己的 DeepSeek Key
→ 填写并核对自己的 SerpAPI Key
→ 选择政策来源
→ 设置每日输出时间
→ 选择简报目录
→ 离线检查
→ Y/N 决定是否立即生成第一份简报
```

客户不需要手动运行 Python 配置命令。

## 立即输出与定时输出

两种方式相互独立。

### 立即输出

在运行菜单选择：

```text
2. 立即输出一份简报
```

确认后马上执行，不等待 08:30、14:00，也不受用户后来设置的其他定时时间限制。

首次安装结束时也会询问：

```text
现在立即生成第一份简报吗？[Y/n]
```

选择 `Y` 或直接回车会立即运行。

### 定时输出

推荐时间是：

```text
08:30
14:00
```

首次安装时客户可以：

```text
Y：使用推荐时间
N：输入自己的时间，例如 09:00,17:30
```

安装后在运行菜单选择：

```text
4. 修改每日定时输出时间
```

客户可以使用 Y/N：

```text
是否启用定时输出
是否保留当前时间
是否恢复推荐时间
```

需要自定义时，只输入一个或多个 `HH:MM` 时间即可，例如：

```text
09:00
09:00,17:30
07:45,12:00,18:15
```

程序自动校验、去重和排序。


## 重要运行规则

“修改每日定时输出时间”只是保存设置。要让程序每天按时执行，需要选择“启动每日定时输出”，并保持该终端或命令提示符窗口打开。

关闭 VS Code 不影响运行。关闭运行调度器的终端、关机或使电脑进入停止进程的深度休眠，会停止定时执行。

## 密钥安全

Key 只写入当前电脑的 `.env`。发行程序会强制排除 `.env`，并在打包前后扫描本机秘密值是否被误复制到其他文件。
