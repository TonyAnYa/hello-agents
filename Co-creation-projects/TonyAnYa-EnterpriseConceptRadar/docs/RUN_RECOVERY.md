# 运行中断与恢复

## 关闭窗口

关闭 VS Code 不会停止程序。关闭正在运行调度器的终端或命令提示符会停止程序。

## 电脑关机或深度休眠

程序停止执行。重新开机后再次运行启动脚本即可。任务会从最近一次成功时间向前增加重叠窗口，降低遗漏政策的风险。

## 单次任务失败

运行状态记录在：

```text
data/runtime/tracking/state/<task_id>.json
```

其中包含：

- 最近开始时间；
- 最近成功时间；
- 失败次数；
- 最近错误；
- 已成功投递的政策指纹。

失败不会把本次政策标记为已成功投递。下次运行仍会在重叠窗口中重新检索和去重。

## 重复启动

任务运行锁位于：

```text
data/runtime/tracking/locks/<task_id>.lock
```

第二个进程会显示“任务已经在运行”，不会重复消耗搜索和模型额度。

## 检查状态

```bash
python scripts/show_status.py
```

该命令不联网。
